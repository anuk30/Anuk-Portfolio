# Anuk Abeysinghe Portfolio

A starter portfolio website built with plain HTML, CSS and JavaScript.

## Folder structure
- index.html
- css/style.css
- js/script.js
- images/
- documents/

## Before viewing
1. Put your CV at `documents/Anuk_Abeysinghe_CV.pdf`
2. Add your own photos to `images/` when ready.
3. Open `index.html` in Chrome, or use VS Code's preview/integrated browser.

The placeholder image panels are intentional so the site works immediately without missing-image icons.
